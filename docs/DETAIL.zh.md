# 会话中心（dsh-session-hub）插件详情

## 它做什么

给每个会话一个 `session` 工具：读会话清单、逐轮摘要、完整对话，并按 id 新建（可同时命名）、重命名、发消息、中断、归档、取消归档、置顶其他会话。

## 三个增值能力

**协作专家指示**：会话头部与「N 个子智能体」并列显示「N 个协作专家」。记录双向往来（我发给别人的、别人发给我的），按会话 id 去重，按最近往来时间倒序。

- 头部前置位是「活动指示器」：空闲显示协作图标，有协作会话运行中显示转圈，二者互斥（与 DSH 子智能体、后台任务的做法一致）。
- 悬停展开列表，每行显示方向（`→` 我发出的 / `←` 我收到的）、会话标题、相对时间与运行状态；点击跳转。
- 归档会话保留在列表并标注「已归档」；DSH 不允许 retain 归档会话的引用，因此点击时提示先取消归档，不擅自改归档状态。
- 键盘：`↓` 打开并聚焦首行，`Esc` 关闭。

**自动回执**：`send` 传 `receipt: true`，目标会话这一轮自然结束时，该轮最终回复自动发回发送方并按对方状态唤醒或排队。同一对会话每进程周期只回一次；被中断或报错的轮次不回执。

**发送方标注**：消息正文首行是发送方的会话引用（`来自 @[标题](dsh-session:…)`），由 DSH 原生渲染成会话标签，接收方一眼看出不是用户本人发的。

## 安全模型

- 子智能体会话拒收（子会话由 subagent 路由持有）。
- 归档会话必须先取消归档才能发消息。
- 发消息默认限同一工作目录，跨目录需显式 `cwd`。
- A→B→A 回环拒绝；自动回执有进程内的对级防循环账本（重启重置）。

## 兼容性

- `engines.dsh: '>=0.2.0'`（SemVer 范围，DSH 启动时校验）。
- 纯插件实现，零 DSH 源码改动；只用公开服务（`tools`、`sessionController`、`sessionProjections`、`agents`、`sessions`、客户端 `slots`/`locale`/`uiWorkspace`）。
- 本地挂载时 `package.json` 的 `name`、`cordis.patch.yml` 的包名、`client.js` 顶部的模块 `id` 三处必须一致。
