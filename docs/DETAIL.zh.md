# 会话中心（dsh-session-hub）插件详情

## 它做什么

给每个会话一个 `session` 工具：读会话清单、逐轮摘要、完整对话，并按 id 新建（可同时命名）、重命名、发消息、中断、归档、取消归档、置顶其他会话。

三个增值能力：

- **协作专家指示**：会话头部显示「N 个协作专家」，悬停列出所有往来会话（标题、状态、最近往来时间、方向），点击跳转。双向计数、按会话去重。
- **自动回执**：`send` 传 `receipt: true`，目标会话这一轮自然结束时，最终回复自动发回发送方并唤醒它。
- **发送方标注**：消息正文首行是发送方的会话引用标签（DSH 原生渲染），接收方一眼可见来源。

## 安全模型

- 子智能体会话拒收（子会话由 subagent 路由持有）。
- 归档会话必须先取消归档。
- 发消息默认限同一工作目录，跨目录需显式 `cwd`。
- A→B→A 回环拒绝；同一对会话的自动回执每进程周期一次（防循环）。

## 兼容性

- `engines.dsh: '>=0.2.0'`（SemVer 范围，DSH 启动时校验）。
- 纯插件实现，零 DSH 源码改动；只用公开服务（`tools`、`sessionController`、`sessionProjections`、`agents`、`sessions`、客户端 `slots`/`locale`）。
