# 截图

主 README 使用同一次「新版发布」场景的浏览器截图，取自[交互演示](../demo/index.html)。

| 截图 | 对应步骤 |
| --- | --- |
| [派发任务](release-dispatch.webp) | 前端任务已投递，输入框准备发送后端任务。也是 README 的演示入口。 |
| [协作专家](release-running.webp) | 两个任务都已发送，头部的协作列表显示两位工程师正在运行。 |
| [接收方](release-receiver.webp) | 前端工程师收到任务，可点击来源引用跳回项目负责人。 |
| [自动回执](release-receipts.webp) | 两位工程师的结果已回到项目负责人。 |

## 旧版素材

| 文件 | 说明 |
| --- | --- |
| `header-idle.webp` | 头部指示器空闲态：协作图标 + 「N 个协作专家」 |
| `header-running.webp` | 头部指示器运行态：转圈 + 计数（与图标互斥，对齐 DSH 子智能体／后台任务） |
| `menu-open.webp` | 悬停展开的往来列表：方向箭头、标题、相对时间与状态 |
| `receiver-mention.webp` | 接收方看到的来源标注：`来自 <会话引用>` + 「引用会话」提示 |
| `tool-call.webp` | `session` 工具调用在会话轨迹中的呈现 |
| `hero.webp` | 旧版封面（源码 `hero.html`，1200×460 @2x） |
| `at-flow.webp` | 跨会话协作四步流程图（源码 `at-flow.html`） |
| `at-picker.webp` | 输入框输入 `@` 弹出的会话选择器 |
| `mascot.webp` | 吉祥物「大肥鱼」（DSH 玩偶形象，透明底；hero 卡的中间人物） |
